# bash_scripts
Collection of my bash scripts for easy usage accross my repositories via git submodule integration (This repo is intended as a submodule for other repos).

The initial collection of scripts stems from my [cloud] repository, where I accumulated bash scripts I thought were becoming more of an independent project than part of /cloud.

The folder `main` contains the bash scripts that serve as a tool. At the time of migrating them to this repo, they were all for usage in [cloud]
